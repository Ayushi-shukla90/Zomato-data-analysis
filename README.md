# 🍽️ Zomato Restaurant Analytics Dashboard

### 📌 Project Overview
Analyzed Zomato restaurant data using **Python, MySQL, Power BI, and Excel** to uncover insights into restaurant performance, customer preferences, cuisine trends, ratings, pricing, and location-based patterns. Built an interactive dashboard to identify top-performing restaurants, popular cuisines, and factors influencing customer engagement.

---

## 🚀 Tools & Technologies
🔹 Python (Pandas, NumPy)  
🔹 MySQL  
🔹 Power BI  
🔹 Microsoft Excel

## 📊 Key Analysis
✔️ Restaurant Distribution by Location  
✔️ Top Rated Restaurants Analysis  
✔️ Most Popular Restaurants by Votes  
✔️ Cuisine Popularity Analysis  
✔️ Online Order & Table Booking Analysis
